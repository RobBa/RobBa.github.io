Pytorch demystified series

July 2026

Ever wondered how PyTorch works beneath the hood, and what engineers do to make it so fast and smooth to run? If yes, this series of blogposts will give you a deep understanding of how these things work in practice.

These posts assume solid C++ knowledge (templates, memory management, build systems) and familiarity with basic ML concepts. CUDA posts assume you are familiar with the basics of CUDA. CPU optimization posts assume familiarity with computer architecture, operating systems, and assembly language.

The series goes as follows:

  1. Tensor interface and Python binding
  2. Autograd engine and full deep learning training loop
  3. Implementing the CUDA backend
  4. Optimizing the CPU backend
